# ChinaIPsTest

## 说明

ChinaIPsTest 规则由上游 blackmatrix7/ios_rule_script 的 Clash 规则自动转换生成，可直接用于 sing-box 的 rule_set。

分流规则是互联网公共服务的域名和 IP 地址汇总，所有数据均收集自互联网公开信息。
